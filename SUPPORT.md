# Support

## Before opening an issue

1. Confirm Node.js 20 or 22 is installed.
2. Run `npm ci` and `npm run check`.
3. Reproduce with a fresh `.data/` directory when possible.
4. Remove credentials, media IDs, article bodies and account metrics from logs.

## Where to ask

- Reproducible product defect: open a bug report.
- Focused product improvement: open a feature request.
- Usage question or design discussion: use GitHub Discussions when enabled.
- Vulnerability or credential exposure: use private security reporting described in `SECURITY.md`.

This is a community-maintained project. There is no guaranteed response time or commercial support SLA.

## Useful diagnostic information

- Operating system
- Node.js and npm versions
- Application version or commit SHA
- Sanitized command output
- Smallest reproduction sequence

Never post `.env` files, `.data/runtime/config`, browser profiles or real WeChat exports.

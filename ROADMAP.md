# Roadmap

The roadmap is directional rather than a promise of delivery dates.

## 1.x priorities

- Guided onboarding and clearer empty states for a new installation.
- Export/import command for portable workspace backups.
- Better provider capability detection and model compatibility messages.
- Pluggable hot-source adapters with per-source health and rate limits.
- Expanded article QA, attribution and experiment reporting.
- English documentation and UI internationalization foundations.

## 2.x candidates

- Postgres storage adapter and safe schema migrations.
- Authentication and role-based access for private network deployments.
- Background jobs and scheduler abstraction.
- Multi-account workspaces with explicit data isolation.
- Object storage adapter for images and article artifacts.

## Non-goals

- Unattended mass publishing.
- Bypassing WeChat platform limits or review requirements.
- Treating trend headlines or model output as verified facts.
- Shipping real account data, private prompts or production credentials in this repository.

# Editorial Room Templates

This directory contains neutral JSON templates for a file-based editorial workflow:

- `article-assignment.template.json`
- `visual-plan.template.json`
- `qa-report.template.json`
- `risk-report.template.json`

Create real run directories outside the repository or under one of the ignored `editorial-room/*` runtime folders. Do not commit article drafts, source downloads, generated images, account identifiers or publication records.
